# アプリ概要
ハロウィンモンスターをモチーフにしたタイプ診断アプリです。
<br>

10個の質問に答えると、自分のタイプに合ったハロウィンモンスターが分かります。
JavaScriptの復習とアウトプットの場として制作しました。

## ご利用上の注意
本アプリは、心理学の考え方を参考に制作したエンターテインメントコンテンツです。学術的・科学的な心理検査や性格診断ではありません。診断結果はあくまでお遊びとして、気軽にお楽しみください！

## シェア機能について
Xで診断結果をシェアできます。

### iPhone・iPadで利用する場合
1. シェアボタンを押しても投稿画面がうまく表示されない場合は、Xアプリを起動してください。
2. その後、診断結果ページに戻り、もう一度シェアボタンを押してください。
<br>
※端末やブラウザ、Xアプリの状態によって、シェア画面への遷移が異なる場合があります。
